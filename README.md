# Page 1 — Problem, Insight, Product

## The Problem

Vietnamese farms, cooperatives, and exporters still exchange lot evidence through **Excel, PDFs, and email**.

The problem is not missing data.

The problem is that a buyer cannot easily know whether a file was changed after it was issued.

**Editable files → disputed evidence → slower buyer verification → risk of lost orders**

## Our Insight

> A buyer should not have to trust OpenAgriX, the farm, or a middleman to know whether a record changed.

Blockchain is not used to certify physical quality.

It is used to make the **history and integrity of agricultural evidence independently verifiable**.

## The Product

OpenAgriX records agricultural evidence on **Solana Devnet**.

**Farm / Cooperative**
→ submits standardized evidence  
→ raw dossier remains off-chain  
→ SHA-256 hash + summary are written on Solana  
→ buyer independently verifies the file against the onchain record

### Evidence supported today

**Harvest · Soil · Carbon · Biodiversity · Honey Quality · Produce Quality**

### Why Solana

- Low-cost writes for many records per season
- Public verification without a trusted database
- Buyers can read evidence without connecting a wallet
- Native path to programmable settlement

**Working prototype:** https://openagrix.com
